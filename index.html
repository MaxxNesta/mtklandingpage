Common questions

How long does it take to go live?

Most teams are running their first module within a few weeks. We import your opening balances, item list and customers, and you add other modules whenever you like.

Can we start with just one module?

Yes. Many teams start with finance or inventory. Modules you add later use the same ledger, so there's nothing to move across.

Does it handle multiple branches and currencies?

MTK supports several companies, branches, warehouses and currencies in one account, with consolidated reports across them.

Can MTK connect to the tools we already use?

Banks, payment gateways and online stores connect through built-in connectors. Anything else can use the open API or a scheduled spreadsheet import.

Can we get our data out?

You can export every table at any time as CSV or Excel. If you leave, we hand over a full export and delete our copy.
